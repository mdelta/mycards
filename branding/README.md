# Branding

App logo (implementation plan R-5, concept A: two loyalty cards, the front one with a barcode).

| File                                                  | Use                                                       |
| ----------------------------------------------------- | --------------------------------------------------------- |
| `logo.svg`                                            | Source artwork on the 108 × 108 adaptive-icon grid        |
| `play-icon-512.png`                                   | Google Play app icon (512 × 512, Play applies the mask)   |
| `feature-graphic-1024x500.png`                        | Google Play feature graphic                               |
| `android/app/src/main/res/drawable/ic_launcher_*.xml` | Adaptive icon background, foreground and monochrome layer |
| `android/app/src/main/res/mipmap-*/ic_launcher*.png`  | Legacy launcher icons (square and round)                  |
| `src/assets/icon/favicon.png`                         | Web favicon                                               |

The PNG files show the visible 72 × 72 middle of the grid. Colors: `#14B8A6` to `#0F766E`
(background gradient), `#99F6E4`, `#5EEAD4`, `#FFFFFF`.
