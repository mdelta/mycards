# ADR-0001: App technology – Capacitor

- Status: accepted
- Date: 2026-11-08
- arc42 reference: 2, 4.1

## Context

The app targets Android only (no iOS) and must be published on Google Play. The product owner
prefers TypeScript web applications and wants to avoid Java/Kotlin.

## Options

Capacitor, React Native/Expo, PWA + Trusted Web Activity, NativeScript, Tauri 2 – compared in
arc42 section 4.1.

## Decision

Use **Capacitor**: the app is a TypeScript web application running in an Android WebView; native
functionality is accessed through Capacitor plugins.

## Consequences

- Nearly all code is TypeScript; the app can be developed and partly tested in a desktop browser.
- Native features rely on community plugins (camera/barcode, SQLite, filesystem, share, brightness).
  Plugin selection is documented per feature.
- Features without a suitable plugin (lock screen, ADR-0006) need a small custom Capacitor plugin
  written in Kotlin. Such code is kept minimal and isolated.
- The Android project (`android/`) is generated by Capacitor and committed; native changes are
  limited to configuration and the custom plugin.
